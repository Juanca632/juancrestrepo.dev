AI workflow

AI in every step, judgment in every step

I use AI agents to build faster, never to think less. They take part in every step, and I stay responsible for what ships.

  1. Design

    I decide the architecture and the trade-offs; AI helps me explore options.

  2. Plan

    The work is split into small tasks, each with a clear way to check it.

  3. Build

    Agents write the code and the tests, several tasks in parallel.

  4. Review

    Reviewer agents and I check every change before it moves on.

  5. Ship

    Automated tests run and the app deploys, with nothing left to manual steps.

Judgment first

Architecture, data model and trade-offs are decided before any agent writes a line. Agents follow a plan; they don't make it.

Every change reviewed

I read the code agents write the way I'd read a teammate's, and automated tests back every change. If I can't explain it, it doesn't ship.

AI inside the product

I also build AI features into apps: agents that use the app's own data as tools, with guardrails so they can't invent answers.

Team adoption

I brought Claude Code and MCP into my team's daily work: shared project rules and automated code review.
